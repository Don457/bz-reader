# 更新日志

## ✨ 新增

- **漫画模式** ：CBZ 漫画单独开一屏，分格、右到左、双页合页、跨页拆半、条漫长图都能调。
- **逐格导览** ：一页多格时逐格跳，白边自动裁掉，灰暗的扫描件能一键修复。
- **双链模板** ：整本导出与复制划线各备四档，简洁、引文、详细、自定义都能改。 [<sub>B 站评论区反馈</sub>](https://pd.qq.com/s/Nb15xen1zz)
- **更新提醒** ：启动时在后台看有没有新版本，有就弹一次，也可以忽略这一版。
- **屏幕常亮模式** ：新增常亮模式，阅读时屏幕不锁，设置里可以开关。
- **图标说明** ：头栏图标悬停给出说明，不再把键位写进设置里。 [<sub>QQ 频道反馈</sub>](https://pd.qq.com/s/Ny9zjevm)

## ⚡ 优化

- **AI 配置** ：AI 配置向基础版开放，自定义通道能带上网关要求的附加请求头。
- **权益下放** ：导出、并排、剪藏、划词解释都进了基础版。
- **插件安装** ：设置里给出 bz 与 bz review 的安装入口，一个去市场、一个去 GitHub，装完回来点启用。
- **字体档名** ：字体长名改叫「原生」「原书」，浮窗与设置页共用一张表。

## 🐛 修复

- **书架分类** ：分类只认手动指定的，不再被 EPUB 自带题材顶掉。 [<sub>QQ 交流群反馈</sub>](https://pd.qq.com/s/N2mh8aj9ll)
- **高分屏留白** ：分页时上半屏那片留白没了，正文吃满高度。 [<sub>QQ 交流群反馈</sub>](https://pd.qq.com/s/N9dspltqs9)
- **AI 连接** ：第三方服务商直连不通时改走 Obsidian 代发，能连上了。 [<sub>QQ 交流群反馈</sub>](https://pd.qq.com/s/Ngur4srpmj)
- **外语界面** ：非简体中文不再显示 QQ 频道出处与更新日志里的群图标。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 点 **浏览**，搜索 **bz Reader**，安装。
3. 启用后左侧出现 bz 图标，从书架开始。
